# Honey Split

Honey Split is an expense-sharing web app designed to help two people track shared expenses, see who paid for each transaction, and calculate who owes whom.

## Current Version — V1

Honey Split currently includes:

- Add shared expenses
- Edit and delete expenses
- Assign an expense to the person who paid
- Save expense data with localStorage
- Group expenses by month and year
- Filter transactions by month
- Calculate monthly spending
- Calculate total number of expenses
- Calculate who owes whom
- Settle up monthly balances
- Preserve settled expense history
